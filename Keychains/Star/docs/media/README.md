# Star media

Real footage supplied by Aloe, split from `IMG_0103.mp4`. Every MP4 contains
**one video stream and no audio**. GIFs are silent by format.

| Clip | Source interval | What it shows |
| --- | --- | --- |

| [Touch reactions](touch-reactions.mp4) · [GIF](touch-reactions.gif) | 6.5–11.6 s | Finger interaction and eye reactions |
| [Battery readout](battery-readout.mp4) · [GIF](battery-readout.gif) | 11.6–16.1 s | Liquid readout while charging |
| [Shake and dizzy](shake-and-dizzy.mp4) · [GIF](shake-and-dizzy.gif) | 16.1–21.9 s | Shake reaction, spiral pupils and recovery |

[Low-battery photo](low-battery.png) shows the red, tired expression.
The [neutral placeholder](neutral-placeholder.svg) reserves one image slot.
Replace its README reference with the future photo when available.

Clips were cropped around the keychain, converted from HLG to SDR, and encoded
as H.264 MP4 at 576 × 720. The GIF copies are 320 × 400 at 12 FPS. Audio, timed
metadata and source location metadata were excluded. The full source recordings
are not included in the repository.

Captions describe the footage, not proof of charge completion.
Generated firmware previews live separately in [animations](../animations/).
