**Star** reacts to touch, tilt and shaking. It has liquid charging animations,
falling stars in always-on mode, and tired red eyes when its battery runs low.
The footage above is silent.

[Controls, videos and setup](Keychains/Star/README.md) ·
[Animations](Keychains/Star/ANIMATIONS.md) ·
[Developer guide](Keychains/Star/docs/DEVELOPMENT.md)

Charging state and percentage are voltage estimates.
[Known limitations](Keychains/Star/README.md#charging-and-battery).
